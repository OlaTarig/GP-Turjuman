# GP-Turjuman
**Turjuman** is our graduation project which is an AI-driven communication system which aims to close the gap between Deaf and hearing participants by enabling seamless, two
way communication. By automatically identifying ArSL gestures from a webcam feed and translating them 
into spoken or written language for hearing users and converting spoken dialogue into a virtual 3D avatar for 
deaf users, this solution seeks to eliminate the dependency on third-party interpreters. This system will not 
only minimize communication delays but also foster autonomy and social inclusion, ensuring that 
communication differences no longer preclude appropriate engagement in the digital age. 

## *Features*
- Android app for online meetings
- Realtime translation from sign language to text
- 3D Hand Avatars for translating from text to sign language
- Captioning for voice
